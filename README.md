# 📺 STC TV — Viewing Analytics & Audience Intelligence

An interactive analytics dashboard built to explore STC TV viewing behavior, content performance, audience patterns, and engagement across more than 1 million viewing-session records.

## 🚀 Live Interactive Dashboard

**[Explore the Dashboard →](YOUR_GITHUB_PAGES_LINK)**

The dashboard is fully interactive, allowing users to filter by genre and content type, explore viewing trends, analyze audience behavior, sort content performance, and interact with visual insights.

## 📊 Project Overview

This project analyzes a large-scale STC TV viewing dataset containing **1,048,575 viewing-session records**.

The analysis focuses on understanding:

- Viewing trends over time
- Content and genre performance
- Movies vs. Series consumption
- Audience behavior and activity levels
- Engagement patterns
- Content popularity
- Data quality and analytical limitations

## 🔍 Key Analytical Areas

### Content Performance
- Top-performing titles
- Genre performance
- Movie vs. Series comparison
- Catalogue size and viewing volume

### Audience Behavior
- Active users
- Viewing activity levels
- Audience engagement patterns
- Genre preferences across audience segments

### Engagement
- Engagement hours
- Session duration
- Viewing distribution
- HD adoption

## 🧹 Data Quality & Methodology

The dataset required several data-quality considerations before analysis.

Key issues identified included:

- Character corruption in a large proportion of program titles
- Inconsistent whitespace in title fields
- Duplicate viewing records
- Extreme session-duration values
- Undefined or missing genre classifications

These issues were assessed and documented rather than being silently removed.

Duration outliers were excluded from engagement-hour and average-session calculations while remaining included in session counts.

Duplicate records were retained because they may represent repeated viewing behavior rather than definite logging errors.

## 📈 Dataset

**Records:** 1,048,575 viewing-session records

**Time Period:** March 2017 – April 2018

The dataset includes information related to:

- Viewing date
- User
- Program
- Program genre
- Content type
- Season and episode
- Viewing duration
- HD availability
- Series and movie classification

## 🎯 Project Objective

The objective of this project was to transform a large and complex viewing dataset into an interactive analytical experience that helps identify content performance, audience behavior, and engagement patterns.

Rather than focusing only on visualization, the project emphasizes **data quality, analytical reasoning, and decision-oriented insights**.

## ⚠️ Limitations

The dataset does not provide sufficient information to reliably analyze:

- Viewer demographics
- Device usage
- Completion rates
- Time of day viewing behavior
- Detailed geographic behavior

These limitations were considered when defining the analytical scope of the dashboard.
